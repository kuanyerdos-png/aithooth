# Qerivo

Qerivo is an AI assistant for dental clinics: it finds patients the clinic has lost, writes to them
(WhatsApp / Telegram / Instagram), answers questions, sells and books them back in.
This repo contains the marketing site (framework-free HTML/CSS/JS) and a FastAPI backend with a mock chat.

## Run locally

```bash
cd backend
python -m venv .venv
# macOS/Linux: source .venv/bin/activate     Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Open http://localhost:8000 . API: `GET /api/health`, `POST /api/chat`.

## Pages (frontend/)

`index` (home) · `product` · `reactivation` (win-back) · `how-it-works` · `integrations` · `pricing` · `demo` (live chat) · `contact` (book a demo)

## Languages: EN / RU / KK

ALL site text lives in one file: `frontend/js/i18n.js`, as `"key": ["English", "Русский", "Қазақша"]`.
HTML uses `data-i18n="key"`. To change a text, edit it there. The header, footer and bottom CTA block
are generated by `frontend/js/app.js`, so they are edited in one place for every page.

## Video

The hero video is `frontend/assets/video/qerivo-hero.mp4` (poster: `qerivo-hero-poster.jpg`).
It must stay inside `frontend/` so both uvicorn and Vercel can serve it.

## Buttons

Every "Book a demo" button has a fixed size (`.btn`, `.btn-sm` in `frontend/css/site.css`),
so Russian / Kazakh / English look identical.

## Chat backend

`backend/app/services/chat_service.py` is a deterministic mock (price, "I'll think about it", time, pain, stop).
Replace `MockChatService` with an OpenAI/Anthropic adapter with the same `reply_to(message, language)` method.

## Deploy to Vercel

`vercel.json` and `api/index.py` are included. Import the repo, keep the root, no build command.
